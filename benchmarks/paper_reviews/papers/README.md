# Reference reviews -- INTERNAL, DO NOT PUBLISH

Hand-written forensic reviews kept as worked examples of the reasoning style this
toolkit is trying to support. They are **not** agent output and should not be
cited as such.

## Why this directory is not publishable

Three independent reasons, each sufficient on its own:

1. **They name live, non-retracted papers by URL** and reach strong conclusions
   about them ("the results should not be trusted"). Publishing that from a
   project account converts a private reading note into a public allegation
   against identifiable authors.
2. **The prose is not ours.** These reviews are third-party authored. Publishing
   them would need the author's agreement, which we do not have on file.
3. **The PDFs are third-party copyrighted articles.** The repository's MIT
   licence covers our code. It does not and cannot license the publishers'
   articles stored alongside it.

## The hazard to watch

This repository is currently **private** (`delton137/forensic-metascience-ai-toolkit`,
collaborators: delton137, gregfitzgerald), which is the only thing keeping the
above contained.

These files are in the git history from the initial commit. **Making the
repository public would publish them retroactively** -- deleting them at that
point would not help, because the history still carries them. If the repository
is ever opened up, this directory has to be removed from history first
(`git filter-repo` or equivalent), not merely deleted from the working tree.

The same applies to the paper corpora under git-LFS.
