# Archive

Dated design notes, reviews, measurements and handoffs whose work is done or
was abandoned. Kept for provenance: why a decision was made, what was
measured, what an earlier pipeline looked like. **Do not treat anything here as
a description of the current system** -- each file opens with a status line
saying what is still true. The current contracts are in `../specs/`.

`pipeline_diagram.pptx` (2026-08-21) is a one-slide picture of the parallel
pipeline that predates the modular refactor and draws the image track as
built in; it is now an optional, separately distributed package.

Split out of current documents on 2026-10-16:
`webapp_db_unbuilt_plans.md` (the hosted-mode, storage-seam and `db-pull`
plans from `docs/specs/webapp_db.md`, never built) and
`workbench_storage_log_2026-09.md` (the dated verification, backfill and reset
logs from `docs/workbench_storage.md`).
