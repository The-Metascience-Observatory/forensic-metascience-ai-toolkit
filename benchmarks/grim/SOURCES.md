# GRIM ground truth: sources

Every source behind the GRIM ground-truth sets: complete references with links, and the DOIs of the papers with GRIM issues. Generated 2026-10-18 from each set's `labels.jsonl`, Crossref metadata and the sources' own pages; a reference without a DOI is given as author, title, date and URL as the page shows them.

Labels are allegations by named third parties, not findings of this toolkit, and a GRIM inconsistency is a fact about printed numbers, not about anyone's conduct. What each status and tier means: [README.md](README.md).
